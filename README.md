# bimestral_3

Planteamiento del problema

Problema:
Actualmente, algunas personas, emprendimientos y pequeñas empresas tienen dificultades para manejar su información y dar a conocer sus servicios debido a que no cuentan con sitios web o sistemas digitales adecuados. En muchos casos, la información se maneja de forma manual o desorganizada, lo que dificulta el acceso a los datos, la comunicación con los clientes y la realización de diferentes actividades.

Aportes:

Como futuro Ingeniero de Sistemas, puedo aportar mis conocimientos en programación, desarrollo de sitios web, bases de datos y tecnologías digitales para crear soluciones que ayuden a resolver estos problemas.

Mi aporte sería desarrollar sitios web funcionales, dinámicos y fáciles de utilizar, junto con bases de datos que permitan almacenar y administrar la información de forma organizada. También podría crear sistemas que automaticen procesos, mejoren la atención a los usuarios y faciliten el acceso a la información.

De esta manera, la tecnología no sería solamente una herramienta, sino una forma de solucionar problemas, mejorar procesos y ayudar al crecimiento de personas, emprendimientos y empresas.


Causas:

Falta de conocimientos sobre programación y desarrollo web.
Poco uso de herramientas tecnológicas para organizar información.
Información almacenada de manera manual o desordenada.
Falta de sitios web que permitan mostrar productos, servicios o información.
Ausencia de bases de datos para almacenar y consultar información fácilmente.
Poco conocimiento sobre la importancia de digitalizar los procesos.

Consecuencias:

Pérdida de tiempo al buscar o actualizar información.
Mayor posibilidad de cometer errores al manejar los datos.
Dificultad para que los clientes encuentren información sobre un negocio o servicio.
Procesos más lentos y poco organizados.
Menores oportunidades de crecimiento y presencia en Internet.
Dificultad para controlar grandes cantidades de información.

Épica 1: Diseño y desarrollo del sitio web

Objetivo: Crear un sitio web moderno, organizado y fácil de utilizar.

HU1: Como usuario, quiero acceder al sitio web desde computador o celular para consultar la información fácilmente.
HU2: Como usuario, quiero encontrar diferentes secciones en el sitio para navegar de manera sencilla.
HU3: Como usuario, quiero que el sitio tenga un diseño agradable y organizado para tener una buena experiencia.
HU4: Como administrador, quiero actualizar el contenido del sitio para mantener la información vigente.



#---------------------------------------------------------------

Épica 2: Gestión de usuarios

Objetivo: Permitir que los usuarios puedan registrarse y utilizar las funciones del sitio.

HU1: Como usuario, quiero registrarme para crear una cuenta en el sitio.
HU2: Como usuario, quiero iniciar sesión para acceder a las funciones disponibles.
HU3: Como usuario, quiero cerrar sesión para proteger mi cuenta.
HU4: Como administrador, quiero gestionar los usuarios registrados para controlar el acceso al sistema.



#----------------------------------------------------------------


Épica 3: Gestión de información y base de datos

Objetivo: Almacenar y organizar la información de manera segura y eficiente.

HU1: Como administrador, quiero registrar información en la base de datos para mantenerla organizada.
HU2: Como administrador, quiero consultar los datos almacenados para encontrar información rápidamente.
HU3: Como administrador, quiero modificar los registros para mantener la información actualizada.
HU4: Como administrador, quiero eliminar información incorrecta para mantener la base de datos organizada.


#-----------------------------------------------------------------

Épica 4: Automatización y funcionalidades

Objetivo: Utilizar la programación para facilitar y agilizar diferentes procesos.

HU1: Como usuario, quiero realizar diferentes acciones desde el sitio web para evitar procesos manuales.
HU2: Como sistema, quiero validar la información ingresada para reducir errores.
HU3: Como usuario, quiero recibir mensajes de confirmación cuando realice una acción para saber si fue exitosa.
HU4: Como administrador, quiero consultar información de forma rápida para facilitar mi trabajo.





#-----------------------------------------------------------------

Épica 5: Seguridad y mantenimiento

Objetivo: Mantener protegida y funcionando correctamente la plataforma.

HU1: Como usuario, quiero que mis datos estén protegidos para mantener mi información segura.
HU2: Como administrador, quiero controlar los permisos de los usuarios para evitar accesos no autorizados.
HU3: Como administrador, quiero detectar y corregir errores para mantener el sitio funcionando correctamente.
HU4: Como administrador, quiero agregar nuevas funciones cuando sea necesario para mejorar el sitio
